# Retail Sales EDA Project

## Files
- `EDA_Retail_Sales_Project.ipynb`: complete Jupyter Notebook
- `retail_sales_sample.csv`: sample dataset included for immediate practice
- `requirements.txt`: Python dependencies

## Run in VS Code / Jupyter
1. Open this folder in VS Code.
2. Open a terminal in this folder.
3. Create and activate a virtual environment:
   ```powershell
   python -m venv venv
   .\venv\Scripts\Activate.ps1
   ```
4. Install packages:
   ```powershell
   python -m pip install -r requirements.txt
   ```
5. Open `EDA_Retail_Sales_Project.ipynb` and select the `venv` Python kernel.
6. Run all cells.

This project uses an included sample dataset with intentionally added missing values and a duplicate row for data-cleaning practice.
